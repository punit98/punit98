## 🔭 What I'm Building

### 📊 `quantified_self` — *Because spreadsheets are for quitters*
A personal data pipeline that turns my workout & wellness CSVs into insights I actually act on.

- **Ingestion:** Apple Shortcuts → Unity Catalog Volume (zero manual steps)
- **Transforms:** Delta Live Tables across Bronze → Silver → Gold layers
